# 📚 Types of Data Structures (Complete List)

---

## 1️⃣ Primitive Data Structures
Basic data types that store a single value.

- Integer
- Float / Double
- Character
- Boolean
- Pointer (C/C++)
- Null / Undefined

---

## 2️⃣ Non-Primitive Data Structures
Store multiple or complex data.

---

## A. Linear Data Structures
Elements are stored sequentially.

### 1. Array
- Static Array
- Dynamic Array (Vector, ArrayList)

### 2. String
- Immutable Strings
- Mutable Strings

### 3. Linked List
- Singly Linked List
- Doubly Linked List
- Circular Linked List
- Circular Doubly Linked List

### 4. Stack (LIFO)
- Array-based Stack
- Linked List-based Stack

### 5. Queue (FIFO)
- Simple Queue
- Circular Queue
- Priority Queue
- Deque (Double Ended Queue)

---

## B. Non-Linear Data Structures
Elements are stored hierarchically or graph-based.

---

## 3️⃣ Tree Data Structures

- Binary Tree
- Binary Search Tree (BST)
- Balanced Trees
  - AVL Tree
  - Red-Black Tree
- Heap
  - Min Heap
  - Max Heap
- Trie (Prefix Tree)
- Segment Tree
- Fenwick Tree (Binary Indexed Tree)
- B-Tree
- B+ Tree
- N-ary Tree
- Threaded Binary Tree
- Cartesian Tree
- Suffix Tree
- Suffix Array

---

## 4️⃣ Graph Data Structures

### Types of Graphs
- Directed Graph
- Undirected Graph
- Weighted Graph
- Unweighted Graph
- Cyclic Graph
- Acyclic Graph
- DAG (Directed Acyclic Graph)
- Complete Graph
- Bipartite Graph

### Graph Representations
- Adjacency Matrix
- Adjacency List
- Edge List

---

## 5️⃣ Hash-Based Data Structures

- Hash Table
- Hash Map
- Hash Set
- Dictionary
- Unordered Map
- Unordered Set

---

## 6️⃣ Advanced / Specialized Data Structures

- Disjoint Set (Union-Find)
- Sparse Table
- Bloom Filter
- LRU Cache
- LFU Cache
- Skip List
- Treap
- Rope
- Interval Tree
- K-D Tree
- Quad Tree
- Octree
- Wavelet Tree

---

## 7️⃣ Persistent Data Structures
Preserve previous versions of data.

- Persistent Stack
- Persistent Queue
- Persistent Tree
- Immutable Data Structures

---

## 8️⃣ Probabilistic Data Structures

- Bloom Filter
- Count-Min Sketch
- HyperLogLog
- Cuckoo Filter

---

## 9️⃣ Abstract Data Types (ADT)
Logical structure, not implementation.

- List
- Stack
- Queue
- Deque
- Set
- Map
- Priority Queue
- Tree
- Graph

---

## 🔟 Data Structures in System Design

- Cache (LRU, LFU)
- Message Queue
- Ring Buffer
- Consistent Hashing
- Merkle Tree
- Log-Structured Merge Tree (LSM Tree)

---

**Main Classification:**

  - Linear
  - Non-Linear

## ⭐ One-Line Definition

> Data Structures are ways to organize and store data efficiently to perform operations like insertion, deletion, searching, and updating.
