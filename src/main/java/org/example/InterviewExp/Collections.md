# 🔥 1. Basic Questions (Must Know)


### ❓ What is Collection Framework?

👉 A set of classes & interfaces to store and manipulate data




### ❓ Difference: `Collection` vs `Collections`



| Term        | Meaning                                    |
| ----------- | ------------------------------------------ |
| Collection  | Interface                                  |
| Collections | Utility class (methods like sort, reverse) |


# ❓ List vs Set vs Map




| Feature    | List | Set         | Map     |
| ---------- | ---- | ----------- | ------- |
| Duplicates | ✔   | ❌          | Keys ❌ |
| Order      | ✔   | ❌ (mostly) | ❌      |
| Index      | ✔   | ❌          | ❌      |

# 🔥 2. List Questions


### ❓ ArrayList vs LinkedList


| Feature       | ArrayList | LinkedList |
| ------------- | --------- | ---------- |
| Access        | Fast      | Slow       |
| Insert/Delete | Slow      | Fast       |
| Memory        | Less      | More       |


## Why ArrayList is fast?

👉 Uses **dynamic array → O(1) access**
